# AI-Supported ESG Reporting Prototype for VSMEs

A self-contained prototype concept for an AI-assisted ESG reporting platform aligned to the EFRAG VSME framework.

## Prototype goals
- Capture environmental, social and governance data.
- Validate values and flag anomalies/inconsistencies.
- Calculate selected ESG KPIs.
- Map data to VSME-style disclosure topics.
- Produce an auditable report-ready output.
- Demonstrate how AI/NLP can assist with evidence extraction and narrative drafting.

## Included prototype
- `index.html`: interactive dashboard, data entry, validation, KPI calculations, AI-assistant simulation, and report preview.
- `sample_data.json`: the project values supplied in the abstract.
- `prototype_architecture.md`: technical architecture and research framing.

## Run
Open `index.html` in a modern browser. No server or external dependency is required.

## Important
This is a research prototype, not a compliance certification tool. The VSME mapping is illustrative and should be reviewed against the current EFRAG VSME requirements before production use.
